# Contribuir a Monitor Cashea

Esta web es independiente y no procesa pagos.

1. Abre un issue o pull request. Explica el cambio y cita una fuente pública con fecha.
2. Para un comercio nuevo incluye: nombre, categoría, ciudades publicadas en la fuente, referencia y fecha de publicación. No infieras disponibilidad por sucursal.
3. Prefiere dos medios independientes o una comunicación verificable del comercio. Una mención antigua no equivale a afiliación actual.
4. No compartas nombres completos de clientes, números de transacción, direcciones personales, credenciales ni capturas privadas.
5. Si fuentes oficiales difieren, refleja la discrepancia; no selecciones el dato que parece más favorable sin pruebas.
6. Ejecuta `npm test` y `npm run validate:data` antes de abrir una propuesta.
7. Una falla DNS, HTTP 403 o timeout de GitHub **no** demuestra una caída general de Cashea.

## Revisión editorial

Cada corrección debe identificar la fuente, la fecha de publicación, el alcance geográfico y el estado del dato: confirmado por la fuente, antiguo o no comprobado. La disponibilidad actual siempre debe confirmarse dentro de la aplicación oficial.
